# Mechanical Design Guide

A beginner-friendly reference for mechanical design: from first sketch to manufacturable part.

## Before You Start
- A laptop that can run CAD software (16 GB RAM recommended)
- A free student license for a CAD tool (SolidWorks, Fusion 360, FreeCAD, or Onshape)
- A notebook, calipers, and curiosity
